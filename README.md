# Kairo

Sistema de información para un establecimiento híbrido de coworking, cafetería y experiencias sociales.

## Cómo correrlo

```bash
cd kairo
npm install
npm start
```

Abre [http://localhost:3000](http://localhost:3000).

## Cuentas de demostración

Clave para todas: `kairo123`

- Dirección: `admin@kairo.local`
- Barista: `barista@kairo.local`
- Cliente con membresía: `valentina@kairo.local`

## Qué cubre

- Espacios, reservas y membresías
- Cafetería, recetas, inventario y ventas
- Experiencias ligadas a espacio, personal, equipos y productos
- Empleados, turnos, equipos, arriendo, servicios y permisos
- Reportes de ocupación, demanda, costos y margen
